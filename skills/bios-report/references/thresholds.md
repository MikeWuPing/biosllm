# 硬件报告判读口径

写报告时按这张表决定"正常/异常"，不要把每一项都写成"正常"——那等于没判断。

| 项 | 正常 | 需要注意 |
|---|---|---|
| SMBIOS 版本 | 2.8 或 3.x | 低于 2.6：部分字段缺失，注明"表较旧" |
| BIOS 版本 | 有厂商与日期 | 日期早于机器出厂日：可能不是最新固件 |
| 内存条 | 每条都有 Part Number 与频率 | 有槽位但无条：空槽，不是缺数据 |
| 内存总量 | 与 memmap 一致 | 两者相差 >5%：可能有内存被保留或未映射 |
| PCI 设备 | 每个都有 vendor:device | 出现 0000:0000：设备未初始化 |
| ACPI 表 | 至少 DSDT + FADT | 缺 DSDT：固件不完整，报告要明确指出 |

## 写报告的口气

- 只说测到的事实，不说"应该"。
- 缺的项写"不可用"，不猜。
- 异常项单独列出来，不要混在表格里让人自己找。
